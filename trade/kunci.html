Sambungkan Binance Testnet

Uang demo. Kunci disimpan di server OCKLU, tidak tampil di chat, dan tidak bisa dibaca lagi dari halaman ini.

  1. Di testnet.binance.vision klik Generate HMAC_SHA256 Key, isi nama bebas, lalu Generate.
  2. Salin API Key dan Secret Key ke kotak di bawah.
  3. Isi kode sekali pakai dari Claude, lalu Simpan.
